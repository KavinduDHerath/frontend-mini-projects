# ⚽ Pong Game by Kavi

A classic retro Pong game built from scratch using HTML5 Canvas, CSS3, and vanilla JavaScript. Test your reflexes against a computer-controlled opponent!

## ✨ Features

* **Win Condition:** Compete in an intense race to 10 points!
* **Difficulty Levels:** Choose between Easy, Medium, and Hard to adjust the AI's speed.
* **Retro Sound Effects:** Generated dynamically using the Web Audio API (no external files needed!) for satisfying bleeps and bloops.
* **Responsive & Mobile Ready:** Scales gracefully to fit different screen sizes and includes touch controls for mobile devices.
* **Visual Flair:** The ball leaves a sleek motion-blur trail as it bounces across the screen.
* **Dynamic Difficulty:** The ball's speed gradually increases with every successful paddle hit, making long rallies increasingly challenging.
* **Modern UI:** A clean, dark-themed interface with neon accents.

## 🚀 How to Run

No special installation is required.

1. Clone or download this repository.
2. Open the folder.
3. Double-click on `index.html` to open it in your default web browser.
4. Click the "Restart Game" button to initialize the audio and start playing!

## 🎮 Controls

* **Mouse:** Move your cursor up and down over the game board to control the left paddle.
* **Keyboard:** Use the **Up (↑)** and **Down (↓)** arrow keys to move the paddle.
* **Touch (Mobile):** Drag your finger up and down on the game board.
* **Difficulty:** Click the Easy, Medium, or Hard buttons below the board to change the AI speed.
* **Restart:** Click the "Restart Game 🔄️" button below the board to reset scores and start a new match.

## 📁 File Structure

* `index.html`: The main markup file containing the game canvas, scoreboard, and difficulty controls.
* `style.css`: Stylesheet for layout, responsive design, button styling, and colors.
* `script.js`: The game logic, including rendering, collision detection, physics, AI movement, touch events, and the Web Audio API integration.
